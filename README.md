This project is a Java application designed to manage training schedules efficiently. It allows users to add new training sessions, retrieve sessions for a specific day, and filter sessions by both day and time. The system ensures data integrity by preventing schedule conflicts and maintaining organized records of groups, coaches, and training sessions.

Key Features:
- Add new training sessions to the schedule.
- Retrieve a list of training sessions for a given day.
- Filter training sessions by day and time.
- Prevent scheduling conflicts through efficient data management.
